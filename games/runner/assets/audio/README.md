当前背景音乐：

```text
darkness-bgm.ogg
```

- 原文件：`10+闇に潜む影.wav`；
- 原格式：44.1 kHz、16-bit、双声道 PCM，18,931,620 字节；
- 网页格式：48 kHz、双声道 OGG/Opus，目标码率 40 kbit/s；
- 压缩后大小：590,483 字节；
- 时长：约 107.33 秒；
- SHA-256：`00E2844C86AAF37F67B7FF30D9227E123247D837EA0E5717BE751422871FCF0F`。

游戏会循环播放该音乐，默认音量由 `game.config.js` 中的 `bgmVolume` 控制。首屏只预读音频元数据，待核心图片加载完成后再播放，避免和游戏画面抢占下载带宽；浏览器拒绝自动播放时，会在玩家第一次点击画面、跳跃或重新开始后重试。

可选音效仍可继续加入：

- `jump.ogg`：跳跃；
- `hit.ogg`：碰撞；
- `milestone.ogg`：每 100 分提示。

新增音频后，应在本文件中记录文件名、作者、来源和授权情况。
