# 素材说明

《柠檬蛇工厂》使用站点维护者提供的六张角色头像：

- `assets/images/skins/cropped/ena.webp`：惠凪；
- `assets/images/skins/cropped/anju.webp`：杏珠；
- `assets/images/skins/cropped/tsukimi.webp`：月望；
- `assets/images/skins/cropped/ririko.webp`：莉莉子；
- `assets/images/skins/cropped/miku.webp`：美玖；
- `assets/images/skins/cropped/nayuka.webp`：那优花。

背景、蛇身、食物、粒子与小地图均由 Canvas 程序绘制。操作音效由 Web Audio API 在本地合成。

背景音乐为站点维护者提供的 `Be brand new.mp3`，未裁切内容，仅转码压缩为 `assets/audio/be-brand-new.ogg`（Opus 立体声，约 64 kbps）。
