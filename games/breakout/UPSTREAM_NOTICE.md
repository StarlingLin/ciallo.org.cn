# 上游来源说明

本游戏的基础玩法参考并改造自 `straker/basic-breakout`：

- 上游项目：Basic Breakout HTML and JavaScript Game；
- 固定提交：`9e2eb0baf8cc542ae08f21bb8f543a093da3fc3d`；
- 上游入口：`breakout.html`；
- 上游许可声明：CC0 1.0 Universal；
- 上游说明称代码可用于个人或商业项目，无须事先取得许可，署名不是强制要求。

当前版本保留了 Canvas 打砖块这一基础思路，但重新组织了页面、样式、配置和游戏逻辑，并新增：

- 分数、生命、三关关卡和通关流程；
- 响应式与高 DPI Canvas；
- 键盘、鼠标、触屏及屏幕按钮控制；
- 暂停、重开、静音和可选背景音乐；
- 可替换的背景、挡板、球、砖块图片及音效接口；
- 球速增长、双耐久砖块、碰撞细分和粒子效果。

站点运行时不依赖上游网站，也不会向上游或其他公网地址发起请求。
