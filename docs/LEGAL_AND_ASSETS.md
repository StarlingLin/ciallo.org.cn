# 素材与许可证边界

## 仓库整体

本仓库同时包含原创站点代码、开源游戏改造代码、用户提供素材和二次加工素材，因此没有一个许可证能够自动覆盖全部文件。仓库公开可见并不代表所有素材都可自由复制、商用或再分发。

每款游戏至少需要保留：

- `UPSTREAM_NOTICE.md`：上游项目、固定提交、作者和许可证；原创游戏留空即可；
- `ASSET_NOTICE.md`：最好附上素材的来源与处理方式；
- 上游许可证要求保留全文时，附带 `LICENSE`；原创代码投稿也应明确选择许可证。

## 投稿者保证

提交 Pull Request 即表示投稿者确认：

1. 对原创内容拥有相应权利，或已经取得允许公开托管、修改和展示的授权；
2. 已按真实情况披露第三方代码和素材来源；
3. 不把“非商业”误认为可以忽略著作权、商标权、肖像权或上游许可证；
4. 若权利人提出合理异议，愿意配合补充证明、替换素材或下架内容。

## 不接受的内容

- 无法说明来源的整包商业游戏资源；
- 破解、解密、绕过付费或去除权利管理信息所得的素材；
- 包含广告、统计、指纹、挖矿、恶意跳转或用户追踪的代码；
- 需要访问投稿者私人服务器才能运行的核心资源；
- 明显用于冒充官方、误导用户或商业牟利的内容。

维护者可以基于风险判断拒绝或移除内容，即使自动检查已经通过。
